## Description

Based on example 5, I created and positioned new spritesheets for a new set of characters, backgrounds, and sound audios using preloads and loads JSON files from online, while adding dynamic visual effects and obstacles using loops and arrays.

---

## Learning Goals

Learning Goals:

- Loads JSON levels (preload)
- Creating and positioning entities using sprite sheets
- Builds Level objects
- Using an event system to trigger gameplay events
- Playing sound effects and music using a sound manager
- Level.js (grid + drawing + tile meaning)
- Player.js (position + movement rules)
